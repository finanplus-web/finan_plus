# Ícone do Finan+ (F+)

Fontes em vetor do ícone do Finan+. O mesmo desenho é usado no app Android, no Finan+ web (PWA) e no Finan+ para Linux.

| Arquivo | Conteúdo |
|---|---|
| `finan-plus-icone.svg` | Ícone completo, com a sombra do símbolo (arquivo mestre). |
| `finan-plus-icone-plano.svg` | O mesmo ícone sem a sombra, para editores e impressão. Tem camadas nomeadas: Fundo, Letra F e Sinal de mais. |
| `finan-plus-simbolo.svg` | Só o F+, com fundo transparente. |
| `finan-plus-uma-cor.svg` e `finan-plus-uma-cor-negativo.svg` | Versões em uma cor (escura e branca). |

**Cores:** fundo `#eef4ff` com os brilhos `#d9e5ff` (azul) e `#ffe7ed` (rosa), que são as cores do tema claro do app. O F usa um degradê de `#5E83EC` para `#3456C4`. O círculo do "+" é `#4269d8`, e o "+" é branco.

**Sombra:** deslocamento vertical de 12, desfoque de 14, cor `#3A4B6E` com 25% de opacidade (valores na escala de 512 px).
